# Sicherheitsrichtlinie

NotchShelf befindet sich aktuell in der Alpha-Phase. Nur der aktuelle `main`-Branch wird aktiv gepflegt.

## Sicherheitslücke melden

Sicherheitsprobleme bitte nicht öffentlich als Issue veröffentlichen. Nutze GitHub Private Vulnerability Reporting, sobald es für das Repository aktiviert wurde.

Eine Meldung sollte enthalten:

- betroffenen Commit oder Version
- technische Beschreibung
- Reproduktionsschritte
- mögliche Auswirkungen
- optional einen Korrekturvorschlag

API-Schlüssel, Passwörter, private Schlüssel, Signierungszertifikate, Provisioning Profiles, Notarisierungsdaten oder persönliche Apple-Team-Informationen dürfen nicht committed werden.
