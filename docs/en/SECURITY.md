# Security Policy

NotchShelf is currently alpha software. Only the current `main` branch is actively maintained.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues. Use GitHub Private Vulnerability Reporting after it is enabled for the repository.

Include:

- affected commit or version
- technical description
- reproduction steps
- possible impact
- optional remediation proposal

Never commit API keys, passwords, private keys, signing certificates, provisioning profiles, notarization credentials, or personal Apple Team information.
